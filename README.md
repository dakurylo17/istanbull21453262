# Istan Bull Groningen

Сайт закусочной Istan Bull (Astraat 23, Groningen): меню, акции, онлайн-заказ на самовывоз с временем готовности, аккаунты со скидкой 10% на первый заказ.

Статический сайт: `index.html`, `styles.css`, `script.js` и папка `img/`. Сборка не нужна — достаточно выложить файлы на любой хостинг (например, GitHub Pages).

**Демо-режим:** заказы и аккаунты пока хранятся только в браузере посетителя. Для работы с рестораном нужен сервер — адрес задаётся в `CONFIG.orderEndpoint` в `script.js`.

Цены, меню и время приготовления настраиваются в начале `script.js`.
